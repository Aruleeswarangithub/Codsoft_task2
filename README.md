# 🌍 Tourist Website - Travel Planner  

Welcome to **Travel Planner**, your ultimate companion for planning unforgettable journeys! This website helps tourists explore exciting destinations, book premium accommodations, and connect with experienced travel guides.  

---

## ✨ Features  

✔ **User-Friendly Navigation** – Easy-to-access sections like Home, About, Services, Packages, and Contact.  
✔ **Travel Guide Section** – Meet expert travel guides for various destinations.  
✔ **Attractive UI** – A clean, responsive, and visually appealing design.  
✔ **Service Highlights** – Premium offerings like first-class flights, luxury hotels, and 24/7 customer support.  
✔ **Call-to-Action Buttons** – Engaging buttons for interaction and lead generation.  

---

## 🛠️ Technologies Used  

🔹 **HTML** – Provides the structure for the website.  
🔹 **CSS** – Enhances the design with an elegant and responsive layout.  
🔹 **JavaScript** – Adds interactive elements like dynamic navigation.

## 📂 File Structure  

📂 `index.html` – The main structure of the website.  
🎨 `styles.css` – The styling for various sections and responsiveness.  
📜 `script.js` – Contains JavaScript for dynamic functionality.  
📂 `images/` – Stores logo and travel guide images.

## 🎨 UI/UX Highlights
